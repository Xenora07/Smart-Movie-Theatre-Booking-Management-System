# Backend

Antigravity will generate the Java Spring Boot Maven application here.

Requirements:
- Java + Spring Boot + Spring Web + Spring Data JPA + MySQL Connector/J.
- Spring Security and BCrypt password hashing.
- Controller → service → repository architecture.
- DTOs, validation, consistent exception handling, role-based authorization.
- Transactional booking with database-backed conflict handling.
- Configuration via environment variables or an ignored local configuration file.
- Tests for core service logic and integration with MySQL where available.

Do not commit credentials or secrets.

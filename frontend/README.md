# Frontend

Antigravity will generate the React + JavaScript + Vite application here.

Requirements:
- Axios service modules for real Spring Boot API calls.
- No hardcoded catalogue or booking data as the source of truth.
- Customer registration/login, movie/show browsing, show-specific seat selection,
  simulated payment, confirmation, booking history.
- Protected admin dashboard with CRUD forms.
- Responsive CSS and loading/error/empty/success states.

Suggested local development port: 5173.
Backend API default base URL: http://localhost:8080/api.
